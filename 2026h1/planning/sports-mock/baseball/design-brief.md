## 1. ページの目的

「海外で野球観戦をしたい / してみたい」日本人トラベラーが、

- 自分が観たい **チーム / 試合 / 場所** を起点に
- Veltraが取り扱う **観戦ツアー / チケット / 送迎 / 宿泊パッケージ**

を横断的に発見し、**最短2クリックでAC詳細ページに到達できる**ようにする。

既存のカテゴリ商品ページ（`/jp/ctg/203895:baseball/`）よりも一段ストーリー性のある「特集トップ」の位置づけ。Klookやエンタメ系の海外サービスをUI参考にしている。

## 2. 想定ペルソナ

### 大前提（全ペルソナ共通）
**Veltraで観戦ツアー／チケットを買う層は、超コアな観戦オタクではない。**
コア層はMLB公式・StubHub等で自力でチケットを買う。Veltra利用者は「観戦は旅行の重要な一部だが、自力でMLB公式と格闘して英語で席を選び球場までUberで行く」のがハードルになる人たち。だからツアー商品としての価値（**観戦チケット手配＋球場送迎＋日本語ガイド＋ホテル／観光セット**）が刺さる、**旅行＋観戦のハイブリッド層**が中心。

### P1. 日本人選手の活躍を観たい（ボリュームゾーン）
- 30〜50代、家族旅行 or 友人旅行・カップル旅行
- **大谷選手をはじめとした日本人選手の所属チームの試合**を観たい（ドジャースだけでなく、メッツの千賀、カブスの鈴木誠也・今永、パドレスのダルビッシュ・松井裕樹、レッドソックスの吉田、エンゼルスの菊池ほか）
- 観戦が旅程の主目的の一つ。ただし英語・現地移動・球場ルールには不安あり
- 関心: 在籍選手の所属チーム / 観戦チケット / 球場までの送迎 / 当日の流れ / 言語対応
- 行動: 注目球団枠の球団カードから入る → ツアー一覧で「送迎付き」「日本語ガイド」で絞る

### P2. アメリカ本場のベースボール・スタジアム体験目的
- 30〜60代、野球好きだが特定球団のコアファンというより「**MLBの本場文化や名球場そのもの**」を観たい
- フェンウェイ・パーク（最古の球場）、リグレー・フィールド（聖地）、ヤンキー・スタジアムなど、**球場そのものが目的**になりがち
- 「行ったことの証拠」として観戦体験を持ち帰りたい。家族・配偶者は野球そこまで好きじゃないこともあるので、ツアーで導線が組まれていると安心
- 関心: 名球場一覧 / 行きやすい都市 / 観戦＋観光のセット商品
- 行動: 都市または地区から入る → 球場名や「観光セット」「日本語ガイド」で絞る

### P3. 旅行先の1つのアクティビティとして観戦
- 20〜50代、目的はあくまで**観光・出張・留学・修学旅行などの旅**であり、行き先がたまたまMLB／海外野球のある都市
- 「せっかくNYに行くなら一晩はヤンキース」「台北行くから楽天モンキーズも観てみる？」のテンション
- 観戦は1試合だけでよく、座席もそこそこ。安く・スムーズに入れることが大事
- 関心: 旅行先の球団 / 価格 / 観光と組み合わせやすいか / アジア野球も含めて選べるか
- 行動: 都市から入る → 価格安い順 / 「観戦チケット付き」だけ絞る、もしくはアジア野球ブロックから入る

## 4. 情報の並べ順とその理由

```
Hero                  ← タイトル＋概要＋主要数値（規模感の即提示）
01 地区から選ぶ        ← Macro filter（「どこ」起点）
02 主要球団から選ぶ    ← Meso filter（「誰の試合」起点・注目球団を強調）
03 観戦ツアー一覧      ← AC到達点。01/02はここの絞り込み状態に繋がる
04 観戦Tips           ← 検討中の補強情報（"買う前に知っておきたい"）
05 観戦ガイド          ← 予約後の使い回しも想定（当日Tips）
06 FAQ                ← 残った不安の解消
Footer
```

### 設計上の主な意思決定

1. **地区 → 球団 → ツアー の漏斗**
   ふらっと来た人は地区から、目的が明確な人は球団から、最初から横並べ比較したい人はツアー一覧へ。3つの入口を上から並べた。

2. **MLB / その他海外野球 のブロック分け**
   メインはあくまでMLB（取扱29球団・ACの大半）。台湾CPBLは「アジアでも野球観戦できますよ」という追加価値の位置づけのため、それを誤認しないよう同セクション内でブロック見出しを分けた（地区・球団・サイドバーで一貫）。

3. **注目球団枠（日本人選手在籍）**
   ボリュームゾーンの **P1（日本人選手の活躍を観たい層）** が真っ先にチームを見つけられるよう、MLBブロックの中で特別枠を最初に置き、残りはデフォルト折りたたみで圧縮。大谷選手のドジャースに限らず、所属する6球団を在籍選手名のピル付きで並べる。
   - 表示順: ドジャース → カブス → パドレス → レッドソックス → メッツ → エンゼルス
   - 各カードに在籍選手名のピルを併載

4. **AC一覧のフィルタ軸**
   - **リーグ**（MLB / CPBL）— 一番粗い
   - **地区**（ア・リーグ東〜CPBL）— MLBファンの慣用軸
   - **都市**（17）— 旅行起点で考える人向け
   - **タイプ**（観戦チケット付き / 送迎付き / プリゲーム / 観光セット / 宿泊パッケージ / 日本語ガイド）— 機能起点
   
   サイドバーは「絞り込みナビ」として左固定（Klook型）。多軸AND、件数は他フィルタ適用後の動的件数。

5. **AC全件を実データ・実画像**
   モックでもダミーは使わない方針。46件すべてVeltra実商品（実URL・実画像・JPY価格・実評価）。これにより:
   - 画像のばらつきもそのまま見せる（実運用の表示崩れリスクを把握）
   - 価格差の幅（¥1,299〜¥399,858）が実感できる
   - フィルタの実効性を本物の分布で検証できる

6. **「ア・リーグ / ナ・リーグ」表記**
   `AL`/`NL` は野球ファン以外に通じない可能性が高いため、日本の慣用に合わせて「ア・リーグ東地区」等に統一。地区カードには `American League East` の英語副題を残してファン向け情報も維持。

7. **地区表記の数値根拠**
   - 対象リーグ **2**（MLB / CPBL）
   - 取扱球団 **31**（MLB 29 + CPBL 2）
   - 観戦ツアー **46**
   - MLB「全30球団」とは謳わない（タンパベイ・レイズだけAC未掲載のため、実数は29）

## 5. コンポーネントの意図

### Hero
- メインキーワード「**MLB・海外野球観戦ツアー・チケット予約**」をH1に（SEO + 一目で何のページか）
- 数値3つで「規模」と「網羅性」をワンショット提示
- 「Veltraがまとめてサポート」のような断定的な売り文句は避け、「Veltraでまとめて検索・予約できます」と機能ベースの表現に

### 地区カード（League card）
- リーグカラーの上辺、地区名、地区の特徴（主要球団のヒント）、本拠地都市
- ホバーで浮き上がる → 「クリックで絞り込み」を示唆
- MLBは6地区、CPBLは1枚

### 球団カード（Club card）
- 球団コード（モノスペース）＋球団名＋地区＋本拠地＋短い紹介文（1〜2行）
- 注目球団は **ゴールド枠 + 「注目」リボン + 在籍日本人選手ピル**
- その他はデフォルトで2行分だけ見せて下フェード → 「残りN球団をすべて見る」ボタンで展開

### ACカード（Tour card）
構成: 画像 → **チームカラー帯（球団コード+球団名）** → 本体（カテゴリ / タイトル / タグ / 評価 / 価格 / CTA）

- **チームカラー帯**: 共通グローブ写真の【MLB観戦チケット】シリーズでも一目で球団識別。複数球団のカードが並んだときの視認性を担保
- **タイトル**: 3行クランプ
- **評価**: 実値（API由来）、無いものは「体験談準備中」
- **価格**: 円表記・左寄せ。`¥xx,xxx〜` 形式。`priceApprox=true` のものは「約」を冠する
- **CTA**: Veltra本体準拠の青ボタン（`#1466d8` 背景・白文字。テキストリンクではなく明確なボタン）

### フィルタサイドバー
- グループ見出しごとに「解除」リンク（部分解除）
- 各オプションに動的件数（他フィルタ適用後の件数）
- 件数0のオプションは透明度を下げて選択不可感を示す
- 上部の active filter chip で個別解除も可

### Tips / Guide / FAQ
- Tips: 6枚のEditor's picks（読み物テイスト、CTAは無くしてリンクアウトを誘発しない）
- Guide: 当日の動き方を4観点（到着・送迎・マナー・グルメ）
- FAQ: シーズン・雨天・座席・送迎・登板予定など、実検討中のよくある疑問

## 6. 既知の制約 / 改善余地（デザインブラッシュアップ前）

- **共通画像のAC**: 【MLB観戦チケット】26球団分は同じグローブ写真。視覚的単調さあり。現状はチームカラー帯が補完しているが、長期的には**球団ロゴ・球場写真**の方が望ましい
- **JPY価格は記事執筆時点の換算値**。為替変動でズレるため、運用上のリフレッシュ方針は要設計（カテゴリAPI直叩きで価格・評価を都度フェッチする等）
- **数値「2 / 31 / 46」は手動マスタ**。データ駆動でレンダしてはいるが、ACデータ自体はJSハードコード。CMS化 or カテゴリAPI連動が改善方向
- **フィルタの「タイプ」**は機能タグの集合。観戦チケット付き / 送迎付きは併存（AND選択時、両方満たすAC）
- **アクセシビリティ**:
  - ACカードはリンク全体クリック領域（入れ子aを回避）
  - サイドバーはチェックボックスで操作可能
  - 折りたたみは `aria-expanded` 連動
  - 改善余地: ライブリージョン（結果件数の動的アナウンス）、フォーカススタイルの強化

## 7. データソースと取得方法（技術メモ）

- AC一覧の構築は `searchActivities` MCP（Veltra実カタログAPI、1回最大5件）を多軸で叩いて収集
- Veltraトップ直叩き（WebFetch）は 403 でブロック。検索APIのみで取得可能
- 検索APIが画像URLを返さなかった6ACは、ユーザー側で商品ページから個別に画像URLを提供してもらい補完済み
- 全AC共通: 画像 / 円価格 / 評価 / レビュー数 / 商品URL は実値。タグ・タイプ・球団・地区は手動アノテーション
