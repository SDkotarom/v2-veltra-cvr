# ラグビー観戦LP 雛形 — 差し替え項目

`baseball/index.html` を型として複製したもの。**中身はまだ本物ではない。**
公開しない前提で置いている。本番化するときは、下の表を全部つぶしてから。

- 実装: `rugby/index.html`（単一ファイル。CSS・JS ともインライン）
- 共通アセット: `../assets/`（CSS テーマ・アイコン・ロゴ）
- 想定URL: `https://www.veltra.com/jp/theme/sports/rugby/`

---

## 1. 差し替えないと出せないもの

| 箇所 | いまの状態 | 必要なこと |
|---|---|---|
| `ACS`（商品12件） | `SAMPLE-01`〜`12`。`url:'#'`、`rating:null`、価格は仮 | 実データ全件（id / url / image / title / price / rating / reviews） |
| `rating` | 全件 null。カードが「体験談準備中」と出る | 実績が出るまで null のまま。**仮の数値を入れない** |
| `image` | 全件同じチケット写真 | 商品ごとの実画像 |
| ヒーロー画像 | `../assets/img/hero-rugby.jpg` が未配置。グラデーションにフォールバック中 | ラグビーのヒーロー画像を PC用・SP用（`-s`）の2枚 |
| `meta robots` | `noindex,nofollow` | 公開時に `index,follow,max-image-preview:large` へ戻す |
| 雛形メモのバー | ページ最上部に `.tpl-note` | ブロックごと削除（CSS の `/* 雛形メモ */` も） |
| `numberOfItems`（JSON-LD） | 12 | 実件数 |

## 3. フィルターの選択肢

いまは仮置き。実商品が決まってから、扱いのある都市・チームだけに絞る。

- `CITY_PRIMARY` / `CITY_EXTRA` — ロンドン・パリ・ダブリン・エディンバラ・カーディフ ＋ 他10都市
- `TEAM_PRIMARY` / `TEAM_EXTRA` — 代表チーム中心。クラブは4つだけ入れてある
- `CATS` — 観戦チケットのみ／＋送迎／＋宿泊／送迎のみ。**野球と共通で、変更不要**

フィルターの見出しは「球団」から「チーム」に変えてある。

## 4. 変えていないもの

型として維持した部分。ここを触ると他種目とズレる。

- ヘッダー・フッター・パンくず・予約メリット3枚の構成
- CSS（`../assets/css/sports-theme.css` と本文内インライン）
- フィルター・並び替え・もっと見る・モバイル用モーダルの挙動
- GTM（`GTM-5KFX5VX`）と `trackEvent()` の送信設計。`LP_CONFIG` だけ `lp_id:'rugby'` に変更
