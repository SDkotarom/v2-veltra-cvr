Area 02 — Competitive landscape

Klook / KKday の日本市場攻勢が継続、ベルトラの「最後の砦」予約フォーム直前で 流出 -17pp。
ユーザーは 「他社も見てから」がデフォルト行動に。

Organic Search 経由ユーザーの ④→⑤ 通過率が 56.19%（ベースライン 73.43% から -17.2pp）。 これは「予約フォームまで来たのに完了しない」現象で、ユーザーは フォームを開いた状態で別タブで競合価格を確認 → そのまま離脱している可能性が極めて高い。 Klook / KKday / じゃらん遊び はクーポン・割引・口コミ量で攻勢を続け、ベルトラの独自価値（無料キャンセル / 日本語サポート / 直前予約可）が UI 上で埋もれている。

01 データ裏付け

流出ライン × 競合プレゼンスの 4 指標

D.01 — Organic 流出
Organic Search ④→⑤ 56.2% / 全体 73.4% から -17.2pp
検索流入は予約意図が高いはずなのに、フォームまで来てから離脱が突出。「比較検討してきたユーザーが最後に他社で決める」典型パターン。 月間 21 万人ラインが同じ場所で消えている。 -17.2pp gap 月 21 万人
D.02 — ブランド検索比率
「veltra ○○」型ブランド検索 vs 「○○ アクティビティ」型ジェネリック検索
推測: ブランド検索比率は低下傾向、ジェネリック検索の依存度が高まっている。ジェネリック検索ユーザーは比較検討意欲が強く、他社流出リスクが高い。Search Console / Ads データで要検証。 仮説段階・要 Analytics 検証
D.03 — 競合主要ターゲットエリア
Klook / KKday のアジア重点、じゃらん遊びの国内重点
ベルトラの主力エリア（沖縄・ハワイ・バリ・台湾）と真っ向ぶつかる。アジアは Klook/KKday の本拠地で口コミ数も豊富。国内はじゃらん遊びがベルトラを上回るシェアの可能性。 沖縄/バリ/台湾で正面競合
D.04 — ベルトラ独自価値
無料キャンセル / 日本語サポート / 直前予約可 — 商品ページで埋もれている
差別化要素は存在するが、商品ページの目立つ位置に集約表示されていない。ユーザーは 「価格と評価だけ見て」競合と比較してしまう。独自価値の見える化が UI 改修ですぐ着手可能。 即実装可能 (effort=S)
02 課題抽出

競合との 4 つの差異点

①
予約フォーム直前の流出ラインに対策がない
Organic Search ④→⑤ -17.2pp は 「予約フォーム開いた状態で別タブ比較」を許している証拠。フォーム上部に独自価値（無料キャンセル等）を集約していれば「もうここで決めよう」と背中を押せるが、現状はフォーム入力に集中する UI で離脱動機を抑止できていない。
推定影響 -0.03pp
②
クーポン・割引キャンペーンの常設化が弱い
Klook/KKday は常時 5〜15% クーポンを表示しているのに対し、ベルトラはセール期間限定。ユーザーが「今ベルトラで買う動機」を作れていない。Q2 のキャンペーン棚卸し必要。
推定影響 -0.01〜-0.02pp
③
レビュー / 口コミ量で競合に見劣りする商品多数
同じアクティビティで Klook が口コミ 1,000+、ベルトラが 100 台というケースが散見。「数」のシグナル不足で 新規ユーザーの信頼形成に時間がかかる。レビュー収集の仕組みを再設計する必要。
推定影響 -0.01pp
④
SEO 流入の質低下（ジェネリック化）
ブランド検索が伸びず「○○ アクティビティ」型のジェネリック検索が中心の場合、比較検討の真ん中で着地している。最終勝者にはなりにくい構造。コンテンツ SEO 強化 + ブランド検索キャンペーンが必要。
推定影響 -0.01pp（中長期で拡大）
