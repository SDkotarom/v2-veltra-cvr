01結論 — GW から通常週へ戻り、実質 CVR は前年水準に近づいた。ただし bot は IP プールを多国分散
post-GW recovery
GW 後半（W19）で 1.16% まで落ちていた実質 CVR が W20 で 1.37% へ +0.22pp 回復。
ユーザーは「直前の駆け込み予約」から「次の旅行を比較検討する」普通のモードへ戻った。
ただし bot は Singapore 単独から Vietnam / China / India へ多国分散し、4 ヶ国合計でほぼ同量を維持。
W19 は GW 後半 4 連休（5/3-5/6）と平日 3 日のミックスで「広く来訪したが買わない」週だった。W20 はカレンダーが通常通り月〜金 + 週末に戻り、「次の旅行を比較検討する」本来のユーザー行動に戻っている。 セッションは raw -25%・実質 -28% と季節的に減ったが、購入数は -15% に留まっており、1 セッションあたりの予約意欲は明確に上がった。
一方、bot は WAF（4/17 適用）で Singapore からの流入が -36% 減ったが、攻撃者が 同じ Chromium Headless 指紋のまま Vietnam・China・India の IP プールへ移籍し、4 ヶ国合計で W19 とほぼ同量（112K/週）を維持している。Country-list ブロック型 WAF の限界が出始めた。

02論拠 — なぜ「post-GW 回復」と判断できるか
3 つの観察で裏付ける：①ユーザー行動の質、②bot の地理シフト、③構造課題は不変。
👤 ユーザー行動 — 「比較検討」へ戻った
セッションあたり購入意欲が回復。W19 は「直前の駆け込み + 連休だけ覗いて帰る」混合だったが、W20 は「次の旅行を比較検討する」通常パターンに復帰。
②→③ 検討率 11.3%
W19 9.32% → W20 11.28%（+1.96pp）。AC ページに来てから「カレンダーを開く」確率が大幅上昇。
④→⑤ 完了率も W19 57.95% → W20 60.08%（+2.13pp）で、フォームまで進んだ層の完走率も改善。
🤖 bot — Singapore 単独から多国分散へ
WAF（4/17 Singapore ブロック）後、同じ Chromium Headless 指紋（activeUsers/sessions ≈ 0.99+）で別国の IP プールから再来。W20 7d の 4ヶ国合算 bot は 112K セッションで W19 とほぼ同量。

SG 単独ブロックは継続稼働するも、country-list 型 WAF の限界。behavioral / fingerprint 検出に高度化が必要。
🏗 構造課題 — BN Top3 は 5 週連続固着
CVR が回復した一方で、セグメント間ギャップ構造は W16 から不変。新規 ④→⑤ -23.5pp / モバイル ①→② -22.5pp / リピーター ①→② -26.7pp。post-GW 回復は季節リズム由来であり、構造課題自体は解消していない。
新規 ④→⑤ 49.2%
ベースライン 72.6% から -23.5pp（W19: 49.1% から -24.3pp）。 month-over-month で 1pp ずつ変動するだけで、構造的な gap はそのまま。
W19 で提案したクロスチーム議論（UIUX + マーケ + 価格 + 商品 + 競合）は引き続き必要。
