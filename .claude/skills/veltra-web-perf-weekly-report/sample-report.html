4分かったことWhat we learned

01

半年かけて悪化している。立ち上がりの問題ではないA six-month slide, not a launch problem

エリアは 3/28 の 1,660ms が最速で、8/29 の 2,714ms まで +1,054ms 悪化した。3月時点では合格していたページが、いま要改善に落ちている。TOP も同期間で 2,514 → 2,805ms。放置して戻る種類の劣化ではない。Area peaked at 1,660ms on Mar 28 and has degraded +1,054ms to 2,714ms by Aug 29. A page that passed in March now needs work. TOP moved 2,514 → 2,805ms over the same period. This does not reverse on its own.

02

検索結果は、サーバー応答だけで目標を超えているOn Search, server response alone exceeds the target

TTFB が 4,851ms。合格ライン 800ms の6倍で、LCP の目標 2,500ms も単体で超えている。画像最適化も preload も、このページでは届かない。サーバー側の打ち手が要る。TTFB is 4,851ms — six times the 800ms target, and above the 2,500ms LCP target by itself. Image work and preload cannot reach this page. It needs a server-side fix.

03

4月中旬に、検索結果で何かが起きたSomething happened to Search in mid-April

4/11 の 3,179ms から 4/18 に 6,148ms へ跳ね、5/16 には 9,392ms まで悪化した。同時期に CLS も 0 から 0.44 へ。これは推定だが、単調な劣化ではなく特定の変更が引き金になった形に見える。当時のリリース内容を当たる価値がある。It jumped from 3,179ms on Apr 11 to 6,148ms on Apr 18, reaching 9,392ms by May 16, with CLS moving 0 → 0.44 over the same weeks. This is an inference, but the shape looks like a specific change rather than gradual drift. Worth checking what shipped then.

04

分母6のうち3ページが測れていないThree of the six pages are not measured

地域とカテゴリーは収集対象に入っておらず、AC詳細は 6/27 以降 CrUX の掲載閾値未満で欠測。この状態では KPI の合格率が計算できない。サイト全体（origin）の値で代用する方法もあるが、それは「そのページの値」ではないため、施策の効果判定には使えない。Region and Category are not in the collection set, and AC detail has been below the CrUX threshold since Jun 27. The KPI pass rate cannot be computed in this state. Origin-level values could be substituted, but they are not that page's values and cannot verify a page-level fix.
