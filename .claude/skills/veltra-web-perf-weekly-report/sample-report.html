5分かったことWhat we learned

01

TOP の実ユーザー LCP は半年ずっと上がり続けているTOP's real-user LCP has climbed for six straight months

2026-03-14 の 2,514ms から 2026-09-05 の 2,880ms まで、26週で +366ms。合格ラインの 2,500ms を下回っていたのは最初の 1週だけで、以降は一度も戻っていない。9/17 のリリースはこの週にはまだ含まれない。From 2,514ms (2026-03-14) to 2,880ms (2026-09-05): +366ms over 26 weeks. It was under the 2,500ms target in the first week only and has never returned. The 9/17 releases are not yet inside this window.

02

9/17 のリリースはラボ値には出ている。実ユーザー値はまだThe 9/17 releases show up in the lab numbers, not yet in real-user data

PSI の6ページ平均は、リリース前5日 32.9 → 後5日 41.6。伸びが最大なのは検索結果で 18.6 → 40.0、次が エリア +7.6、AC詳細 +7.0。一方、PSI が日次で返す URL単位の実ユーザー LCP は、検索結果だけ 6,290ms（9/12）→ 6,146ms（9/23）と下がり始め、TOP は 2,887 → 2,931ms と上がり続けている。The six-page PSI mean went from 32.9 (five days before) to 41.6 (five days after). Search moved most, 18.6 to 40.0, then Area (+7.6) and AC detail (+7.0). Meanwhile the URL-level real-user LCP that PSI returns daily has started falling for Search only — 6,290ms (9/12) to 6,146ms (9/23) — while TOP keeps rising, 2,887 to 2,931ms.

03

週次の CrUX 収集が 9/13 で止まり、その回も途中で落ちているWeekly CrUX collection stopped on 9/13, and that run died partway

crux_weekly の最新 collected_at は 2026-09-13。それまで週1回動いていたので、9/20 の回が無い。さらに 9/13 の回は TOP を書き終えたあと エリア の 2026-08-22 で終わっており、AC詳細と検索結果の行が1つも無い。このため今回増えたのは TOP の 2026-09-05 の1週だけで、他の5ページは 2026-08-29 のままになっている。The newest collected_at in crux_weekly is 2026-09-13. It had been running weekly, so the 9/20 run is missing. The 9/13 run itself ends at Area's 2026-08-22 row after finishing TOP, with no rows at all for AC detail or Search. So the only week gained is TOP's 2026-09-05; the other five pages still sit at 2026-08-29.

04

PSI が日次で返す実ユーザー LCP は、ページによってサイト全体の値に化けているThe daily real-user LCP from PSI silently falls back to the site-wide value

9/24 時点で 地域・カテゴリー・AC詳細 の field_lcp_p75_ms はどれも 2,223ms で完全に一致している。URL単位のデータが無いページには origin（サイト全体）の値が返るためで、この3ページの数値としては使えない。逆に TOP 2,931 / エリア 2,800 / 検索結果 6,146 は互いに異なるので URL単位と判断できる。As of 9/24, field_lcp_p75_ms reads exactly 2,223ms for Region, Category and AC detail alike. Pages with no URL-level data get the origin (site-wide) value back, so the number is unusable for those three. TOP (2,931), Area (2,800) and Search (6,146) differ from each other, so those are URL-level.
