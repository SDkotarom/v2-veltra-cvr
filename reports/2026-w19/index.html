01緊急 — GW なのに前年水準を大きく下回る
URGENT — Cross-team action required
観光予約のピークである GW W19 で CVR が前年比 -0.33pp。
集客は +51%（657K→993K）増えたのに、購入は +3.7%（9,814→10,175）しか伸びていない。
月 ¥75M の機会損失 — UIUX 単独では絶対に解けない構造課題。
通常 GW 週は「旅行直前の予約確定」需要が集中して CVR が上昇するはずの期間。それが 2025 W19 1.492% → 2026 W19 実質 1.16%（推定、bot 除外後）と -0.33pp 後退している。
集客の伸び（+51%）と購入の伸び（+3.7%）の乖離は 「広告で広く集めたが買わない」状態を示しており、サイト UX の問題だけでは説明できない。 マーケティング / 価格 / 商品 / パートナー / 競合分析の各チームと至急議論し、UIUX 改善と並走で根本対策を打つ必要がある。

🏗 UIUX 構造課題 -0.07pp
BN Top3 が 4 週連続固着（新規 ④→⑤ -24.3pp / モバイル ①→² -24.7pp / リピーター ①→² -28.6pp）。 前年も同じ構造課題は存在したが、解消されていない＝持続的劣化要因。
対応 UIUX Design Squad / MIB 開発 ／ 既に audit 済、Sprint 投入待ち
📢 マーケ流入質劣化 -0.08pp
Direct +51% sess / Paid Search 大幅増だが CVR 0.5〜1.4%と低い。bot 除外しても「広く集めたが買わない」流入が増えている疑い。 SEM 入札 / ターゲティング / KPI 設計の見直しが必要。
対応 マーケティングチーム ／ SEM ROAS、Direct トラフィック純化、ターゲット ABM 見直し
💴 価格/為替 -0.06pp
4/20 為替マージン変更（EU 3.9% / TWD・SGD・MYR 0% / 他 2.9%）の純効果が未測定。 円安進行 + パートナー価格上昇でベルトラの実効価格が競合に対して劣位の可能性。
対応 価格戦略 / Revenue Management ／ マージン変更純効果、競合価格弾性、ダイナミックプライシング検討
📦 商品/在庫 -0.05pp
GW 向け人気エリア（沖縄・ハワイ・バリ等）で 在庫切れ・売り切れ・新商品不足が発生していなかったか未検証。 来訪したがピッタリの商品が見つからない＝離脱の温床。
対応 商品企画 / パートナーチーム ／ GW 期間中の在庫稼働率、欠品ログ、新商品投入リズム
⚔ 競合シフト -0.05pp
Klook / KKday / じゃらん遊び の GW キャンペーン優位性。 ユーザーが予約フォームまで来てから「他社も見てから」離脱（Organic Search ④→⑤ -17.0pp ＝ 約 21 万人 / 月の流出ライン）。
対応 競合分析 / ブランド戦略 ／ 競合 GW 価格 / キャンペーン / レビュー数比較、独自価値（無料キャンセル等）の上部訴求
📊 ②→³ 弱化 + その他 -0.02pp
W19 で ②→³ AC→検討率が WoW -2.52pp。デバイス mix shift（モバイル比率 53.1%、前年から数 pp 増）も全体 CVR を引き下げ。
対応 Analytics / Data チーム ／ W20 通常週で ②→³ 季節 vs 恒常を判別、mix shift の trend 追跡

04緊急クロスチーム会議のアジェンダ草案（5/12週開催推奨）
UIUX チーム単独では -0.07pp しか吸収できない。残り -0.26pp を埋めるためにマーケ / 価格 / 商品 / 競合分析を巻き込んだ緊急ミーティングが必要。各チームへの問いを以下に整理。
📢 マーケティングチーム
GW 期間中の広告投資 ROAS と CVR 寄与を即時棚卸し
SEM・ディスプレイ・SNS 各チャネルの投資額 × ROAS × CVR の前年比較。「集めたのに買われない」セッションがどの広告から来ているか特定。Direct 流入の純化（bot 除外運用）も同期化。
💴 価格戦略 / Revenue Management
4/20 為替マージン変更の純効果 + 競合価格モニタリング
通貨別（EU 3.9% / 0% アジア / 他 2.9%）の CVR 変動を W18-W19 で測定。Klook / KKday と人気商品の価格差を可視化、円安局面の戦略を再設計。
📦 商品企画 / パートナー
GW 期間の欠品・在庫稼働ログ抽出 + 来期供給契約
5/3-5/9 で人気エリア（沖縄・ハワイ・バリ・台湾）の在庫切れ件数。欠品時の代替商品誘導率。GW 翌週（W20-21）も繁忙期は続く想定で来期の供給契約強化。
⚔ 競合分析 / ブランド
Klook / KKday の GW キャンペーン構造分析
競合の GW 期間キャンペーン（クーポン / 割引率 / バンドル）を一覧化。ベルトラの独自価値（無料キャンセル・日本語サポート・直前予約可）が上位に来ているか UX 監査。
🛡 SRE / インフラ
WAF を behavioral detection に高度化 + フォレンジック共有
SG AWS DC bot は WAF（4/17）後も baseline の 4.1 倍残存。IP/UA ベースの追加ブロックは追いかけっこなので、クリック分布 / 滞在時間 / フィンガープリント等を組み合わせた behavioral signal 検出ルールへ upgrade。
📊 Analytics / Data
CVR 3 軸併記運用 + GW 取り逃しコホート分析
raw / 実質 / 前年同期の 3 軸併記を kpi.html に実装。W19 で予約しなかった高意向セッションのコホート分析、CRM 連携で再リターゲット可能か検討。
