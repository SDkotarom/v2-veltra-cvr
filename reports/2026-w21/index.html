01結論 — CVR が崩落したのではない。WAF が技術的に破られて bot が大規模再来し、見かけの分母が膨張した
data-quality incident
Singapore × Chrome × Win bot がWAF を突破して大規模再来、5/20（水）単日 195,750 セッションで W20 ピーク（27K/日）の 7倍規模に。
セッション +62% に対し購入はほぼ横ばい（+0.2%）—— 来訪が増えたのではなく、分母が機械的に水増しされた週。
実質 CVR は W20 1.37% → W21 1.37% でフラット、ユーザー行動は構造的に変化していない。
週次 raw 数字を見ると「セッション +62% / 購入 +0.2% / CVR -0.45pp」で大崩壊に見える。だがこれは bot による分母希釈であり、ユーザー行動の悪化ではない。
WAF（4/17 Singapore IP プールブロック）は W16-W20 では Singapore 単独ピーク -71% を維持していたが、W21 で攻撃者が同じ Singapore IP プールへの再進入経路を獲得した模様。さらに China / Vietnam / Indonesia / Hong Kong / India / Brazil / Philippines / Germany / Malaysia へ同指紋（Chromium Headless × Chrome × Windows × activeUsers/sessions ≈ 1.0）が拡散。
bot 除外後の実質指標で見ると、W20 から W21 への変化は 実質 CVR -0.004pp（実質的にフラット）。post-GW 通常週として安定継続している。経営報告は引き続き raw / 実質 / 前年同期 の 3軸併記運用が必要（W17 以降のルール）。

🏗 構造課題 — BN Top3 は 6 週連続固着

新規 ④→⑤ 49.5%
ベースライン 72.0% から -22.6pp（W20: 49.2% から -23.5pp）。 W16〜W21 で 1pp 以内の微変動のみ。構造的な gap はそのまま。
夏休み・お盆（7-8月）は CVR 1.48〜1.54% 帯で過去 2 年安定してきたが、bot を放置すれば見かけ CVR が 0.7-0.9% 帯に沈み、経営報告が誤誘導される。
