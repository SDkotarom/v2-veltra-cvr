GlobalTOP のレイアウト・コミュニケーション設計 最優先

Kotarofutagi
背景（なぜ今か）
  • グローバル向けの新基盤サイトが第1弾リリース済み（EN・多言語）。インバウンド・海外顧客が 海外／日本国内 を予約する想定の基盤。
  • 展開順：まずグローバル → 次に日本人→日本国内も新基盤へ → 日本人→海外は新基盤にするか未定（グローバルモデルを日本ローカルに落とすと、データの持ち方等が最適でないことがあるため）。
  • 現行 /jp は日本人向けに国内旅行と海外旅行の動線が混在。サイト全部が変わるわけではなく、国内＝新基盤／海外＝現行で UI/UX がガラッと変わる。
  • さらに変わるのは「検索→AC 詳細」だけ。予約フォーム・マイページは一旦現行のまま（今後きれいに揃えていく予定）。
問課題
  • 行き先で体験が別物になる。国内（新基盤）と海外（現行）で UI/UX がガラッと変わり、同じ Traveler が行き先によって違うサイトに出る。境界が見えず戸惑う。
  • 旅程の途中で基盤が切り替わる。変わるのは「検索→AC 詳細」だけで、予約フォーム・マイページは現行のまま。AC 詳細まで新基盤で来て予約に進むと現行 UI に切り替わる継ぎ目があり、不信・離脱を生む。
  • 切替の予告・説明がない。これから変わる／今変わったことを Traveler に伝える手段がない。
  • 現行（日本→海外＝売上の大半）を触るリスク。据え置きが前提だが、動線整理で劣化させないこと。
方打ち手方針
  • ① 行き先での振り分けを明快に 国内＝新基盤／海外＝現行を、Traveler が行き先で迷わず選べる入口にする。
  • ② 基盤の"継ぎ目"を滑らかに繋ぐ 検索→AC 詳細（新基盤）→予約フォーム（現行）で UI が変わる箇所を、驚かせず橋渡しする。
  • ③ 事前・切替時のコミュニケーション設計 これから変わる／今切り替わったことを、ラベル・注意書き・通知で丁寧に伝える。
  • ④ 現行の非劣化を制約に置く 売上の大半＝現行（日本→海外）の体験を、動線整理のために落とさない。
具具体案
  • 行き先で選ぶ入口／GlobalTOP で「国内旅行（新基盤）」「海外旅行（現行）」を明示的に振り分ける UI。
  • 継ぎ目の橋渡し／AC 詳細（新基盤）→予約フォーム（現行）で UI が変わる箇所に、一貫したロゴ・導線・文言や「予約手続きに進みます」の橋渡しを置く。
  • 事前・切替時の告知／別サイト・別デザインへ移ることをラベル・注意書き・通知で伝える（必要なら中間の説明）。
  • 現行導線の保全／予約フォーム・マイページは現行のまま。据え置き前提を踏まえ、劣化させない（今後きれいに揃える前提）。
  • 新基盤との整合／新基盤コンセプト資料と情報構造・言葉づかいを揃える。
継ぎ目でつまずかせず、予約完了まで運ぶ。
